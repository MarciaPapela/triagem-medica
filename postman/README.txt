Triagem Médica API - Postman

Conteúdo:
- Triagem_Medica_API.postman_collection.json
- Triagem_Medica_Local.postman_environment.json

Como usar:
1. Abra o Postman.
2. Clique em Import.
3. Importe os dois ficheiros JSON.
4. Selecione o environment "Triagem Medica Local".
5. Execute primeiro: Autenticação > Login Admin.
6. O token JWT será guardado automaticamente na variável "token".
7. Teste os demais endpoints.
